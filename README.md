Entry for the make.fun bounty [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f).

The entry is a single funny line:

**My to-do list and I are in a long-distance relationship: we never meet, but we think about each other constantly.**

`main.py` (stdlib only) copies `entry.txt` verbatim to the output path
(`/output/entry.txt` by default; `ENTRY_OUTPUT` / `OUTPUT_DIR` /
`MAKEFUN_OUTPUT_DIR` override it), resolving every path from its own
location, never from the working directory.
